# SPEC

扩展在 PI TUI 底部状态栏中展示 token 流式输出的速率，要求：

1. token 速率仅统计 token 流式输出的情况，其它情况不需要考虑。
2. 在流式过程中，⚡ 标志颜色用绿色展示。在非流式过程中，颜色恢复成 `dim`。
3. 关于 token 速率的展示：
   1. token 速率在流式输出过程中，token 速率大于 50 tokens/s 则显示绿色，10 tokens/s ~ 50 tokens/s 每秒则显示黄色，小于 10 tokens/s 则显示红色。
   2. 由于 token 的速率仅表示流式输出过程中的速率，其它情况不统计。所以在非流式输出的过程，token 速率的数字直接用 `dim` 颜色来展示即可，速率的数字保持最后一次变更的数字即可，不需要做屏蔽。
4. 实现的代码需要注意性能
